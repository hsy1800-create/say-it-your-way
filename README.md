# Say It Your Way

선생님 모델 책을 화면 맨 위에 펼쳐 놓고, 그 책의 정해진 문장 빈칸에 내 이야기를 넣어 영어로 써 보는 웹앱입니다. 초등 3~6학년 원격 영어 종이책 수업(2~8차시)에 맞춰 만들었습니다.

**주소: https://hsy1800-create.github.io/say-it-your-way/** (Firebase 프로젝트 `say-it-your-way`에 연결됨. 선생님은 구글로 로그인하고, 아이들은 자기 번호 링크를 눌러 들어와요)

- **학생**: 선생님이 보내 준 자기 번호 링크(1~12번)를 누르면 바로 들어와요. 앱 주소로 오면 번호 버튼을 눌러요. 맨 위에 선생님 책이 두 쪽 펼쳐져 있고, 그 아래에서 쪽마다 문장 빈칸에 내 이야기를 넣어요(★ 쉽게 / ★★ 선생님 책처럼 / ★★★ 도전). 넣을 낱말은 ‘낱말 찾기’에서 우리말로 찾아 바로 넣어요. 듣기, 혼자 말해보기, 문장 키우기, 책 사진 올리기가 있어요.
- **선생님**: 아이들이 쓰는 문장과 찾아본 말이 관전판에 실시간으로 떠요. 막힌 아이에게 “이렇게도 말해요” 카드를 보내고, 못 찾은 말에 한 번 답하면 반 전체에 알려줘요. 문장 벽, 책 사진, 모델 책 전자책, 오늘의 덩어리 화면이 있어요.

## 1. GitHub에 올리기

1. GitHub에서 새 저장소를 만들고, 이 폴더의 파일을 모두 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. **Actions** 탭에서 배포가 끝나면 `https://<아이디>.github.io/<저장소 이름>/` 주소가 생깁니다.

이 상태는 **체험 모드**입니다. 한 컴퓨터에서 탭 두 개(선생님, 학생)를 열면 실시간 연결을 볼 수 있어요. 아이들 노트북과 연결하려면 2번을 합니다.

## 2. Firebase 연결하기(무료 요금제)

> 이미 연결해 두었습니다(프로젝트 `say-it-your-way`, 데이터 위치 서울). 아래는 새로 만들 때의 순서입니다. `firestore.rules`를 고치면 Firebase 콘솔 → Firestore Database → 규칙 탭에 다시 붙여 넣고 **게시**해야 반영됩니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다.
2. **Authentication → 로그인 방법**에서 **익명**과 **Google**을 켭니다.
3. **Authentication → 설정 → 승인된 도메인**에 `<아이디>.github.io`를 추가합니다.
4. **Firestore Database**를 만들고, **규칙** 탭에 이 폴더의 `firestore.rules` 내용을 붙여 넣고 게시합니다.
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가**를 누르고, 나오는 `firebaseConfig`를 `src/firebase-config.js`에 붙여 넣습니다.
6. GitHub에 다시 올리면 자동으로 배포됩니다.
7. 선생님 구글 계정으로 앱에 한 번 로그인한 뒤, Firestore에 `classes/<반 이름>` 문서(`name`, `lesson: 2`, `youglish: false`, `teacherUid: <선생님 UID>`)를 만들고 그 문서 이름을 `src/config.js`의 `ROOM`에 적습니다. 앱에서는 반을 새로 만들 수 없습니다.

사진은 줄여서(300KB 이하) Firestore에 저장하므로 무료 요금제로 충분합니다.

## 3. 내용 바꾸기

| 바꾸고 싶은 것 | 고칠 곳 |
| --- | --- |
| 모델 책 그림 | `public/books/lesson2/cover.webp` 처럼 들어 있어요(표지 `cover`, 쪽 `p1`~`p6`, 뒷표지 `back`). 새 그림은 같은 이름의 `.webp`나 `.png`로 바꿔 넣으면 돼요 |
| 모델 책 문장, 생각 질문, 문장틀(빈칸은 `___{우리말 힌트}`), 오늘의 덩어리 | `src/data/books.json` |
| 낱말 사전(우리말, 찾는 말, 영어, 지난 일 꼴) | `src/data/words.json` |
| 표현사전(원어민 표현, 쉬운 표현, 찾는 말) | `src/data/phrases.json` |
| 첫 화면 마스코트 | `public/art/mascot.webp` (`.png`도 돼요, 없으면 안 보여요) |
| 접기 영상 | `src/config.js`의 `FOLD_VIDEO_URL` |

GitHub 웹에서 파일을 열고 연필 아이콘으로 고친 뒤 저장하면, 몇 분 뒤 자동으로 반영됩니다. 그림 프롬프트는 `prompts/` 폴더에 있습니다.

**소리**: 모델 책 문장, 책 속 낱말, 문장틀, 오늘의 덩어리, 낱말 사전, 표현사전은 미리 만든 원어민 목소리 파일(`public/audio/`)로 들려요. 아이가 직접 쓴 문장처럼 파일이 없는 글은 크롬·엣지에 들어 있는 영어 목소리로 읽어요. 영어 목소리가 없는 브라우저에서는 한국어 목소리로 읽지 않고 “크롬이나 엣지에서 열어 주세요”라고 알려 줘요. 문장이나 낱말을 새로 넣었다면, Claude에게 “소리 파일 다시 만들어 줘”라고 하면 새 문장도 원어민 목소리 파일로 바뀌어요(`scripts/audio-list.mjs` → `scripts/make-audio.py`).

## 4. 지키는 것

- 실명, 학교명, 얼굴 사진, 위치를 받지 않습니다. 학생은 번호나 별명으로만 들어옵니다.
- 학생은 번호로만 들어오고, 자기 기록과 문장 벽만 봅니다. 다른 아이의 기록은 볼 수 없습니다(`firestore.rules`).
- 혼자 말해보기 녹음은 학생 노트북에만 있고 어디에도 올라가지 않습니다.
- 유글리시는 13세 미만 서비스라 제한 모드로 열고, 선생님이 설정에서 켤 때만 학생에게 보입니다.
- 학기 끝에는 설정 → **반 기록 모두 지우기**로 정리합니다.
- 가정통신문으로 선생님이 아이들의 우리말 답, 검색어, 문장, 책 사진을 본다는 것을 미리 알려 주세요.
