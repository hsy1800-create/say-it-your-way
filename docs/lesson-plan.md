# 생각을 꺼내는 영어 종이책 — 7차시 지도안 & 웹앱 기획


## 왜 이렇게 설계했나: 문제와 네 가지 원칙

아이들이 입을 닫는 것은 할 말이 없어서가 아니라, 하고 싶은 말과 할 수 있는 영어 사이가 너무 멀어서다. 7권의 책은 매 차시 그 거리를 줄이는 장치다.

지금 수업에서 일어나는 일:

1. 하고 싶은 말은 많다. 한국어로는 이미 생각이 풍부하다.
2. 영어로 어떻게 하는지 모른다. 입력이 부족하다.
3. 질문이 전부 선생님 한 명에게 몰린다.
4. 기다리는 동안 생각이 끊기고, ‘틀리면 안 된다’는 감각까지 더해져 멈춘다.

### 원칙 1. 생각은 한국어로, 구조는 국어 시간에서, 영어는 덩어리로

아이들은 국어 시간에 소개하는 글, 설명하는 글, 주장하는 글, 겪은 일을 쓴 글의 짜임을 이미 배웠다. 7권의 책은 그 짜임을 영어 6쪽에 그대로 옮긴다. 영어는 낱말이 아니라 문장 덩어리로 준다. “The best part is ~” 하나가 수십 가지 생각을 꺼낸다.

### 원칙 2. 모르는 말은 비워두지 말고 ★한글로

생각이 끊기지 않는 것이 먼저다. 모르는 부분은 한글로 쓰고 ★를 붙인 뒤 다음 쪽으로 간다. ★가 남아 있어도 책은 완성이다. 아이들은 막혀도 잘 묻지 않는다. 그래서 묻게 하지 않고, 아이가 웹앱에 쓴 우리말과 검색이 선생님 화면에 그대로 보이게 한다. 선생님이 먼저 다가간다.

### 원칙 3. “틀렸어” 대신 “이렇게도 말해요”

교사는 내용에 먼저 반응한다(“Really? Why?”). 표현은 고쳐주지 않고 바른 형태로 다시 말해준다. 아이가 “I go beach yesterday”라고 하면 “Oh, you went to the beach yesterday? Fun!”으로 받는다. 빨간 펜은 쓰지 않고, 웹앱도 정답·오답을 표시하지 않는다.

### 원칙 4. 문장은 선생님 책에서, 내용은 내가

문장의 뼈대는 그날의 선생님 책에서 빌린다. 웹앱은 선생님 책을 화면 맨 위에 펼쳐 두고, 그 쪽 문장을 그대로 따른 문장틀을 준다. 빈칸에 들어갈 내 이야기는 아이가 정하고, 영어로 모르는 낱말은 우리말로 찾아 넣는다. 쪽마다 ‘생각해 보기’ 질문을 함께 보여 줘서, 빈칸이 정답 맞히기가 아니라 내 이야기를 넣는 자리가 되게 한다.

### 7권 한눈에

| 차시 | 책 제목 | 국어 시간의 글 | 생각을 꺼내는 핵심 덩어리 |
| --- | --- | --- | --- |
| 1(진행 완료) | 나 소개 | 나를 소개하는 글 | 이미 진행한 차시 |
| 2 | Let Me Introduce My ___ | 인물을 소개하는 글 | We always ~ together. / When I’m ~, he(she) ~. |
| 3 | Not Just “I Like Chicken” | 대상을 자세히 설명하는 글 | The best part is ~. / When I ~, I feel ~. |
| 4 | How to ___ Like an Expert | 방법을 설명하는 글 | First, ~. / Don’t forget to ~. |
| 5 | The Day I ___ | 겪은 일을 쓴 글 | One day, ~. / Suddenly, ~. |
| 6 | My Big Opinion | 주장하는 글 | I think ~ because ~. / Some people say ~, but ~. |
| 7 | If I Could ___ | 상상하여 쓴 글 | If I could ~, I would ~. |
| 8 | Dear Me | 마음을 전하는 글(편지) | I’m proud that ~. / I hope ~. |

1차시 나 소개에서 출발해 내 사람 → 좋아하는 것 → 잘하는 것 → 겪은 일 → 생각 → 상상으로 넓혀 간 뒤, 8차시에 다시 ‘나’로 돌아온다. 8차시에 1차시 책을 나란히 펼치면 아이들이 스스로 달라진 문장을 본다.

## 매 차시 공통: 40분 ‘책 한 권’ 루틴

일곱 차시 모두 같은 7단계로 돈다. 순서가 익숙해지면 원격수업에서 안내에 드는 시간이 줄고, 그만큼 쓰는 시간이 늘어난다.

| 시간 | 단계 | 하는 일 | 원격수업 운영 |
| --- | --- | --- | --- |
| 0–4분 | ① 선생님 책 | 웹앱 전자책으로 모델 책을 읽어준다(그림·문장·소리). 이것이 그날의 입력이다. | 전자책 화면 공유. 아이들은 반응 이모지로 |
| 4–10분 | ② 오늘의 덩어리 | 핵심 덩어리 3개: 듣기 → 따라 말하기 → 내 말로 바꿔 채팅에 쓰기 | ‘채팅 폭포’: 모두 써두고 “3, 2, 1”에 동시에 엔터. 누가 틀렸는지 눈에 띄지 않는다 |
| 10–14분 | ③ 접기 + 표지 | 다 같이 책 접기, 표지에 제목·이름·작은 그림 | 접기 영상을 같이 틀고 따라 접는다 |
| 14–18분 | ④ 생각 떠올리기 | 펼친 선생님 책을 보며 쪽마다 ‘생각해 보기’ 질문에 대한 내 이야기를 떠올리고, 책에 연필로 우리말 메모를 한다 | 선생님 책은 아이들 화면 맨 위에 늘 펼쳐져 있다 |
| 18–33분 | ⑤ 쪼개고 영어로 + 그리기 | 선생님 책 문장틀의 빈칸에 내 이야기를 넣어 쓴다. 모르는 낱말은 우리말로 찾아 넣는다. 작은 그림 | 교사는 관전판에서 아이들 문장과 검색어를 보고, 막힌 아이에게 먼저 카드를 보낸다 |
| 33–35분 | ⑥ 뒷표지 | 독자에게 던지는 질문 한 줄 | 시간이 모자라면 집에서 |
| 35–40분 | ⑦ 책 수다 | 교사가 문장 벽에서 3~4문장을 골라 앱 소리로 들려준다. 원하는 아이만 마이크로 직접 읽는다. 친구들은 채팅으로 반응 | 책을 펼쳐 노트북 카메라로 찍어 웹앱에 올린다. 못 찾은 말은 관전판에 이미 모여 있다 |

뒷표지는 본문을 다 쓴 뒤에 쓴다. 내용이 있어야 독자에게 던질 질문이 생기고, 그 질문이 ⑦ 책 수다의 재료가 된다. 40분에 6쪽은 빠듯하다. 최소 기준은 ‘쪽마다 문장 1개 + 연필 그림’이고, 색칠은 집에서 마무리해도 된다.

책 수다의 반응 덩어리(모든 차시 공통): Me too! / Really? / Why? / That’s cool! / I want to try it! — 특히 “Why?”는 읽는 친구가 한 문장 더 말하게 만드는 질문이다.

마이크를 켜지 않아도 모든 단계에 참여할 수 있게 한다. ②의 따라 말하기는 마이크를 끈 채로 해도 된다. 각 차시 흐름표의 ‘읽는다’는 문장 벽의 앱 소리로 들려주는 것이 기본이고, 직접 읽고 싶은 아이만 마이크를 켠다. 듣기는 웹앱의 원어민 영상(유글리시)으로 채운다.

### 문장 키우기 카드: “I like chicken”을 넘어서는 법

여섯 장의 카드를 2차시에 나눠 주고 8차시까지 책상 옆에 둔다. 교사는 문법 대신 어떤 카드를 썼는지에 반응한다(“You used ‘but’! Nice!”).

| 카드 | 덩어리 | I like chicken. → |
| --- | --- | --- |
| ① 이유 | because ~ | I like chicken because it’s crunchy. |
| ② 반전 | but ~ | I like chicken, but I don’t like the bones. |
| ③ 콕 집기 | especially ~ | I like chicken, especially the wings. |
| ④ 때 | When I ~, ~ | When I eat chicken, I feel like a king. |
| ⑤ 마음 | It makes me ~. / I feel ~. | It makes me so happy. |
| ⑥ 예시 | like ~ / For example, ~ | I like fried food, like chicken and French fries. |

### 학년별 수준: 아이가 쪽마다 스스로 고른다

- ⭐ (3~4학년 기본): 문장틀의 빈칸 채우기, 쪽마다 1문장, 카드 ①②⑤
- ⭐⭐ (5~6학년 기본): 문장틀 + 키우기 카드 1장, 쪽마다 1~2문장, 카드 전부
- ⭐⭐⭐ (도전): 틀 없이 내 문장, 한 문장에 카드 2장 (I like chicken, especially the wings, because they’re crunchy.)

학년으로 정해주지 않고 쪽마다 고르게 한다. 3학년도 하고 싶은 말이 큰 쪽에서는 ⭐⭐⭐를 고른다.

### 우리말에서 영어로 가는 다리: 쉽게 쪼개기

우리말로 쓴 한 줄을 바로 영어로 옮기려 하면 막힌다. 그 사이에 ‘쉽게 쪼개기’를 한 번 거친다. 쪼개면 대부분의 조각이 이미 들은 덩어리 안으로 들어온다.

| 단계 | 예시 |
| --- | --- |
| 우리말 그대로 | 떡볶이가 너무 매워서 눈물이 났는데 그래도 계속 먹었다. |
| 쉽게 쪼개기 | 떡볶이 매워. / 나 울었어. / 그래도 더 먹었어. |
| 영어로(혼자 힘으로) | It’s so spicy. / I cried! / But I ate more. |
| 원어민 아이라면(앱·선생님) | My mouth was on fire, but I couldn’t stop eating! |

쪼개는 규칙 세 가지:

1. 한 문장에 생각 하나.
2. ‘나는’, ‘그건’처럼 누가·무엇이를 꼭 넣는다.
3. 어려운 말은 쉬운 말로 바꾼다(눈물이 났다 → 울었다, 계속 먹었다 → 더 먹었다).

2차시 ② 단계에서 선생님이 한 번 시범을 보이고, 그 뒤로는 ⑤ 단계의 첫 습관으로 둔다. 원어민 아이들도 모르는 낱말은 아는 말로 돌려 말한다.

쪼개기는 혼자 쓸 때의 다리다. 앱과 선생님은 그 위에 원어민 아이가 실제로 쓰는 말을 얹어준다. 조금 어려워도 아이가 하고 싶었던 말이면 그 표현이 더 오래 남는다. 원어민 표현은 번역한 문장보다 짧은 경우가 많아서, 책 한 쪽에도 들어간다.

### 아이가 묻지 않아도 되는 흐름

1. 아이는 웹앱 맨 위에 펼친 선생님 책을 보며, 그 쪽 문장틀의 빈칸에 내 이야기를 넣는다. 쓰는 문장은 선생님 관전판에 그대로 보인다.
2. 영어로 모르는 낱말은 ‘낱말 찾기’에서 우리말로 찾아 빈칸에 바로 넣는다. 찾아본 말도 선생님에게 보인다.
3. 사전에 없는 말은 관전판의 ‘못 찾은 말’에 저절로 모인다. 아이는 책에 ★한글로 쓰고 다음 쪽으로 넘어간다.
4. 교사는 관전판을 보고 막힌 아이에게 먼저 “이렇게도 말해요” 카드를 보낸다. 여러 아이가 막힌 말은 ‘못 찾은 말’에 한 번 답하면 반 전체에 알려진다.

아이는 한 번도 묻지 않아도 된다. 한 아이의 ★가 반 전체의 입력이 된다.

수업이 끝나면 이 ★들을 웹앱 표현사전에 추가한다. 차시가 쌓일수록 앱이 ‘우리 반 아이들이 실제로 하고 싶었던 말’로 채워진다.

### 준비물과 사전 안내(학부모 안내 1회)

- A4 용지 10장(7권 + 여분), 가위, 연필·지우개, 색연필 또는 사인펜
- 문장 키우기 카드(인쇄본 또는 사진으로 저장)
- 노트북 한 대: 화상수업 창과 웹앱 창을 나란히 띄운다
- 웹앱 반 코드와 내 번호(가정통신문으로 안내)

### 8쪽 종이책 접는 법(매 차시 함께 접기)

1. A4를 가로로 놓고 위아래로 반 접었다 편다.
2. 좌우로 반, 다시 반 접었다 편다. 펼치면 주름이 8칸(2줄 × 4칸)이다.
3. 좌우로 반만 접은 채, 접힌 모서리에서 가운데 가로 주름을 따라 다음 세로 주름까지만 자른다.
4. 펼쳤다가 위아래로 길게 반 접고, 양끝을 가운데로 밀면 자른 구멍이 벌어지며 십자 모양이 된다.
5. 한쪽으로 눌러 책 모양으로 정리한다. 표지, 1~6쪽, 뒷표지 순서다.

원격에서는 설명보다 영상이 빠르다. 1분짜리 접기 영상을 웹앱에 넣어두고, 매 차시 ③ 단계에서 같이 틀어 따라 접는다.

## 2차시 · Let Me Introduce My ___ — 나의 소중한 사람

**목표** 소중한 사람(또는 반려동물) 한 명을 골라, 겨모습을 넘어 성격·함께하는 일·그 사람만의 특별한 점까지 소개한다.

**국어 연결** 인물을 소개하는 글. 1차시 ‘나를 소개하는 책’에서 ‘다른 사람을 소개하는 책’으로 넓힌다.

**교사 준비** 모델 책 1권, 문장 키우기 카드 파일(이번 차시에 처음 나눔), 쉽게 쪼개기 시범 문장 하나.

누구든 괜찮다. 가족이 아니어도 된다. 절친, 사촌, 학원 선생님, 반려동물 모두 좋다. 기준은 ‘내가 할 말이 많은 사람’이다. 실명 대신 My mom, My best friend처럼 써도 되고, 사진 대신 그림으로 그린다.

### 오늘의 덩어리

- ⭐ This is my ___. / He(She) is ___. / He(She) likes ___.
- ⭐⭐ We always ___ together. / When I’m ___, he(she) ___.
- ⭐⭐⭐ He(She) is the kind of person who ___. / I love it when he(she) ___.

he와 she가 헷갈리면 이름을 그대로 반복해도 된다(Grandma is strong. Grandma likes flowers.). 뜻은 그대로 통한다.

### 6쪽 설계와 선생님 모델 책

예시는 선생님의 실제 사람으로 바꿔 쓴다. 구체적인 장면이 하나씩 들어갈수록 아이들도 자기 장면을 떠올린다.

| 쪽 | 무엇을 | 문장틀 | 선생님 책 예시 |
| --- | --- | --- | --- |
| 표지 | 제목, 그 사람 얼굴 | Let Me Introduce My ___ / by ___ | Let Me Introduce My Grandma |
| 1 | 누구인지 | This is my ___. | This is my grandma. She lives near the sea. |
| 2 | 겨모습과 반전 | He(She) looks ___, but ___. | She looks small, but she is super strong. She carries big bags of rice! |
| 3 | 좋아하는 것 | He(She) likes ___, especially ___. | She likes flowers, especially roses. Her garden is full of them. |
| 4 | 함께하는 일 | We always ___ together. | We always watch dramas together. She cries every time! |
| 5 | 그 사람만의 특별한 점 | When I’m ___, he(she) ___. | When I’m sick, she makes me rice porridge. |
| 6 | 내 마음 | I want to say, “___.” | I want to say, “Thank you, Grandma. I love you.” |
| 뒷표지 | 독자에게 질문 | Who is YOUR special person? | Who is YOUR special person? |

**쪽별 생각 질문**(웹앱에서 문장틀보다 먼저 보이는 질문)

1. 누구야? 나랑 어떤 사이야?
2. 겨으로 보면 어떤 사람 같아? 그런데 사실은?
3. 그 사람이 정말 좋아하는 건 뭐야? 그중에서도 특히?
4. 둘이 자주 같이 하는 게 뭐야?
5. 내가 힘들거나 아플 때 그 사람은 뭘 해줘?
6. 그 사람한테 꼭 하고 싶은 말은?

### 40분 흐름

| 시간 | 단계 | 교사 | 학생 |

## 3차시 · Not Just “I Like Chicken” — 좋아하는 것을 끝까지 말하기

**목표** 좋아하는 것 하나를 감각·이유·기억으로 키워, 왜 좋은지를 6쪽 동안 끝까지 말한다.

**국어 연결** 대상을 자세히 설명하는 글: 감각적 표현과 까닭.

**교사 준비** 모델 책 1권.

음식이 아니어도 된다. 게임, 장소, 인형, 동물, 계절, 운동 모두 같은 틀로 쓸 수 있다. 게임이라면 2쪽은 “It’s fast and exciting.”, 3쪽은 “The best part is the boss level.”이 된다.

- ⭐⭐ The best part is ___. / When I ___, I feel ___.
- ⭐⭐⭐ It reminds me of ___. / I could ___ every day.

## 4차시 · How to ___ Like an Expert — 내가 전문가인 것

**목표** 내가 잘 아는 것의 방법을 순서대로 설명하고, 전문가만 아는 꿀팁을 꺼낸다.

**국어 연결** 방법을 설명하는 글: 차례와 주의할 점.

**교사 준비** 모델 책 1권, 주제 아이디어 화면 한 장.

주제 아이디어: How to make cup ramen / win at rock-paper-scissors / make Mom say yes / take care of a hamster / draw a cat / beat level 1 / wake up on Monday. 아이들은 생각보다 전문 분야가 많다. 누구나 하나는 어른보다 잘 아는 게 있다.

### 오늘의 덩어리

- ⭐ First, ___. Next, ___. Then, ___. Finally, ___.
- ⭐⭐ Don’t forget to ___. / Be careful! Don’t ___.
- ⭐⭐⭐ Here’s my secret tip: ___. / If you ___, ___.

명령문은 문법으로 설명하지 않는다. “하는 말(동사)로 시작하면 시키는 말이 된다” 한 마디면 충분하다. 자주 쓰는 동사 6개(put, pour, mix, wait, cut, press)는 몸으로 익힌다.

| --- | --- | --- | --- |

| 1 | 전문가 자랑 | I’m a ___ expert. Trust me! | I’m a cup ramen expert. Trust me! |
| 2 | 준비물 | You need ___, ___, and ___. | You need cup ramen, hot water, cheese, and chopsticks. |
| 3 | 첫 단계 | First, ___. | First, open the lid halfway and put in the soup powder. |
| 4 | 다음 단계 | Next, ___. Then, ___. | Next, pour hot water up to the line. Then, close the lid and wait for three minutes. |

| 뒷표지 | 독자에게 한마디 | Are you an expert now? Try it! | Are you a ramen expert now? Try it! |

## 5차시 · The Day I ___ — 내가 겪은 일 이야기

**목표** 겪은 일 하나를 ‘언제·어디 → 사건 → 마음 → 끝’의 흐름으로 이야기한다.

**국어 연결** 겪은 일을 쓴 글, 이야기의 흐름(처음–가운데–끝).

**교사 준비** 모델 책 1권, 제목 예시 화면 한 장.

제목 예시: The Day I Got Lost / Lost My Tooth / Won the Game / Saw Snow for the First Time / My Dog Ran Away / Broke Mom’s Cup.

### 오늘의 덩어리

- ⭐ I went to ___. / I saw ___. / I was so ___.
- ⭐⭐ One day, ___. / Suddenly, ___. / In the end, ___.
- ⭐⭐⭐ I couldn’t believe it! / I’ll never forget ___.
- 소리 말: Splash! Boom! Oops! Ouch! Yay! — 그림의 말풍선에 넣는다. 3학년이 특히 좋아한다.

과거형 규칙은 가르치지 않는다. went, saw, ate, was, got, lost, found, cried 8개만 덩어리로 준다. 현재형으로 써도 이야기가 통하면 그대로 두고, 읽을 때 과거형으로 다시 말해준다.

- 3쪽에 ‘갑자기’ 같은 사건의 전환이 있는가.
- 4·6쪽에 마음 낱말이 있는가.

## 6차시 · My Big Opinion — 나는 이렇게 생각해

**목표** 질문 하나에 내 생각을 정하고, 까닭 두 개와 반대 의견까지 말한다.

**국어 연결** 주장하는 글: 주장, 근거, 반대 의견 생각하기, 정리.

**교사 준비** 모델 책 1권, 질문 목록 화면 한 장.

질문 목록: Cats or dogs? / Summer or winter? / Online class or school? / Should kids have smartphones? / Is homework good? / Is it okay to eat dessert first? — ‘Online class or school?’은 원격수업을 듣는 아이들에게 가장 할 말이 많은 질문이다.

### 오늘의 덩어리

- ⭐ I think ___. / I like ___ better.
- ⭐⭐ I think ___ because ___. / Also, ___.
- ⭐⭐⭐ Some people say ___, but ___. / That’s why I think ___.

5쪽의 반대 의견이 이 책의 핵심이다. “다른 사람은 이렇게 말하지만”을 쓰는 순간, 아이는 남의 자리에서 내 생각을 한 번 더 본다. 국어 시간에 배운 반론의 아주 작은 버전이다.

### 6쪽 설계와 선생님 모델 책

| 쪽 | 무엇을 | 문장틀 | 선생님 책 예시 |
| --- | --- | --- | --- |
| 표지 | 제목, 그림 | My Big Opinion: ___? / by ___ | My Big Opinion: Cats or Dogs? |
| 1 | 질문 | Question: ___? | Question: Cats or dogs? Which are better? |
| 2 | 내 생각 | I think ___. | I think cats are better than dogs. |
| 3 | 까닭 1 | First, ___. | First, cats are quiet. They don’t bark at night. |
| 4 | 까닭 2 | Also, ___. | Also, you don’t need to walk them. That’s great on rainy days! |
| 5 | 반대 의견 받기 | Some people say ___, but ___. | Some people say cats are cold, but my cat sleeps on my face every morning. |
| 6 | 정리 | That’s why I think ___. | That’s why I think cats are the best. Sorry, dog lovers! |
| 뒷표지 | 독자에게 질문 | What do YOU think? | What do YOU think? Cats or dogs? |

**쪽별 생각 질문**(웹앱에서 문장틀보다 먼저 보이는 질문)

1. 어떤 질문에 대해 말할 거야?
2. 너의 생각은? 한 문장으로!
3. 그렇게 생각하는 첫 번째 까닭은?
4. 또 다른 까닭은?
5. 반대편 친구라면 뭐라고 할까? 거기에 너는 뭐라고 답할래?
6. 그래서 결국 너의 생각은?

## 7차시 · If I Could ___ — 상상하면 무엇이든

**목표** 현실에 없는 상황을 상상하고, 하고 싶은 것·까닭·하지 않을 것까지 펼친다.

**국어 연결** 상상하여 쓴 글.

**교사 준비** 모델 책 1권, 상상 카드 화면 한 장.

상상 카드: If I Could Fly / If I Were Invisible for a Day / If I Were the Principal / If I Were a Cat / If I Could Talk to Animals / If I Could Stop Time.

### 오늘의 덩어리

- ⭐ If I could ___, I would ___. (어렵면 I want to ___.)
- ⭐⭐ First, I would ___. / I would ___ because ___.
- ⭐⭐⭐ But I would never ___. / It would be ___!

If I could ~, I would ~는 문법으로는 어렵다. 통째로 익히는 덩어리로 다루고, 3~4학년은 I would 대신 I want to로 써도 된다. 5쪽 ‘하지 않을 것’은 상상 속에서도 지키고 싶은 선이라, 아이의 가치관이 드러나는 쪽이다.

### 6쪽 설계와 선생님 모델 책

| 쪽 | 무엇을 | 문장틀 | 선생님 책 예시 |
| --- | --- | --- | --- |
| 표지 | 제목, 그림 | If I ___ / by ___ | If I Were Invisible for a Day |
| 1 | 상상 열기 | If I were(could) ___… | If I were invisible for one day… |
| 2 | 첫 번째로 | First, I would ___. | First, I would sneak into the teachers’ room and eat all the snacks. |
| 3 | 그다음 | Then, I would ___. | Then, I would sit next to my cat and watch her all day. |
| 4 | 까닭 | I would ___ because ___. | I would go to the zoo at night because I want to see the animals sleep. |
| 5 | 하지 않을 것 | But I would never ___. | But I would never read my friends’ diaries. That’s not okay. |
| 6 | 마음 | It would be ___! | It would be fun, but a little lonely. At night, I would come back and say, “I’m home!” |
| 뒷표지 | 독자에게 질문 | If you could ___, what would you do? | If you were invisible, what would you do? |

**쪽별 생각 질문**(웹앱에서 문장틀보다 먼저 보이는 질문)

1. 어떤 상상을 해볼까?
2. 그렇게 되면 제일 먼저 뭘 할 거야?
3. 그다음엔 뭘 하고 싶어?
4. 꼭 하고 싶은 일 하나와 그 까닭은?
5. 그래도 절대 안 할 일은? 왜?
6. 해보면 기분이 어떨 것 같아?

## 8차시 · Dear Me — 지금의 나에게, 다음의 나에게

**목표** 지금의 자랑·걱정·배운 것·바람을 꺼내고 미래의 나에게 한마디를 남긴다. 1차시 나 소개 책과 나란히 놓고 달라진 점을 본다.

**국어 연결** 마음을 전하는 글(편지).

**교사 준비** 모델 책 1권, “1차시 책 꺼내오기” 사전 안내, 지난 7권 사진을 모은 학급 게시판 화면.

3쪽(걱정)은 발표하지 않아도 된다고 미리 말해둔다. 걱정 쪽에 마음이 쓰이는 내용이 보이면 수업 뒤 따로 연락하고 학교 상담 절차를 따른다.

### 오늘의 덩어리

- ⭐ I’m proud of ___. / I’m worried about ___. / I hope ___.
- ⭐⭐ I’m proud that I ___. / Sometimes I worry that ___. / Next year, I want to ___.
- ⭐⭐⭐ I learned that ___. / Remember, ___. / Don’t forget ___.

### 6쪽 설계와 선생님 모델 책

선생님 책의 3쪽 걱정은 솔직하게 쓴다. 선생님에게도 걱정이 있다는 걸 보여주면 아이들도 마음 쪽을 쓴다.

| 쪽 | 무엇을 | 문장틀 | 선생님 책 예시 |
| --- | --- | --- | --- |
| 표지 | 제목, 지금의 내 얼굴 | Dear Me / by ___ | Dear Me |
| 1 | 지금의 나 | Dear me, right now I’m ___. | Dear me, right now I’m teaching English online, and I love my students’ little books. |
| 2 | 자랑 | I’m proud that I ___. | I’m proud that I made eight little books with my students. |
| 3 | 걱정 | Sometimes I worry that ___. | Sometimes I worry that my students are scared to speak English. |
| 4 | 배운 것 | I learned that ___. | I learned that everyone has a lot to say. It’s okay to start in Korean. |
| 5 | 바람 | Next year, I want to ___. | Next year, I want to talk with my students in English for one whole class. |
| 6 | 나에게 한마디 | Remember, ___. | Remember, mistakes are okay. Just keep talking. |
| 뒷표지 | 다시 열어볼 날 | Open this book on ___. | Open this book next October. |

6. 미래의 나에게 꼭 해주고 싶은 한마디는?

## 웹앱 기획: Say It Your Way (GitHub · Firebase)

화면 맨 위에 그날의 선생님 책을 펼쳐 두고, 아이가 그 책의 정해진 문장 빈칸에 자기 이야기를 넣어 쓰는 앱이다. 넣고 싶은 낱말은 우리말로 찾아 바로 넣는다. 아이들은 노트북에서 화상수업 창 옆에 띄워 쓰고, 묻지 않아도 우리말·검색·문장이 선생님 관전판에 실시간으로 보인다. 그날의 모델 책도 앱 안의 전자책으로 본다. 앱은 GitHub Pages에, 실시간 데이터는 Firebase 무료 요금제(Spark)에 둔다.

### 누가, 언제 쓰나

| 사람 | 수업 장면 | 화면 흐름 |
| --- | --- | --- |
| 학생 | 노트북에서 화상수업 창 옆에 나란히. ④ 우리말 쓰기부터 ⑦ 사진 올리기까지 | 반 코드 + 번호(또는 별명) → 오늘의 책 → 쪽마다 생각 질문에 우리말 → 원어민 표현 고르기 → 내 문장 → 사진 올리기 |
| 교사 | ① 전자책 화면 공유, ② 덩어리 큰 화면, ④~⑤ 관전과 도움, ⑦ 문장 벽 | 교사 로그인 → 반 만들기(코드) → 전자책 / 관전판 / 문장 벽 |

### 모델 책: 맨 위에 펼친 책

- 학생 화면과 선생님 화면 모두 맨 위에 실제 책처럼 두 쪽을 펼쳐 가장 크게 보여 준다. 차시마다 표지, 1~6쪽, 뒷표지 8장이다. 한 장에 그림, 영어 문장, 소리가 들어간다.
- 쪽 넘기기, 문장 듣기(보통/느리게), 낱말을 누르면 그 낱말만 듣기, 우리말 뜻 보기 버튼이 있다.
- 화면 공유용 전체 화면을 지원한다. 읽어주는 동안 그 문장을 강조 표시한다.
- 그림은 GPT로 만든다. 프롬프트와 파일 이름 규칙은 prompts 폴더를 따른다(예: books/lesson2/p1.png). 문장은 그림에 넣지 않고 앱이 글자로 얹는다. 문장을 고쳐도 그림을 다시 만들 필요가 없다.
- 접기 영상(1분)도 전자책 첫 화면에 둔다.

### 학생 화면 기능

| 순위 | 기능 | 하는 일 |
| --- | --- | --- |
| 1 | 펼친 선생님 책 | 화면 맨 위에 모델 책을 두 쪽 펼침으로 크게 보여 준다. 그림 아래에 영어 문장이 있고, 문장 듣기·낱말 듣기·우리말 뜻이 있다. 지금 쓰는 쪽이 표시되고, 쪽을 누르면 그 쪽을 쓴다. |
| 2 | 정해진 문장 빈칸 쓰기 | 선생님 책 문장을 그대로 따른 문장틀의 빈칸(우리말 힌트 있음)에 내 이야기를 넣는다. ★ 쉽게 / ★★ 선생님 책처럼 / ★★★ 도전 중에서 고르고, He·She도 고른다. |
| 3 | 낱말 찾기 | 빈칸에 넣을 말을 우리말로 찾으면 낱말(지난 일 꼴 포함)과 표현이 나오고, 누르면 고른 빈칸에 들어간다. 무엇을 찾을지 모르면 묶음(사람, 동물, 음식, 장소…)에서 고른다. 검색어는 선생님에게 보이고, 못 찾은 말은 ‘못 찾은 말’로 모인다. |
| 4 | 듣기 | 모든 영어를 앱이 읽어준다(보통/느리게). ‘원어민 영상’ 버튼을 누르면 유글리시에서 실제 원어민이 그 표현을 말하는 장면이 나온다. |
| 5 | 혼자 말해보기 | 내 목소리를 녹음해 바로 들어본다. 녹음은 내 노트북에만 있고 어디에도 올라가지 않는다. |
| 6 | 내 문장 + 선생님 카드 | 쓰는 문장이 선생님에게 실시간으로 보이고, 선생님이 보낸 “이렇게도 말해요” 카드가 그 쪽에 뜬다. |
| 7 | 문장 키우기 | because, but 같은 카드를 누르면 ‘직접 고쳐 쓰기’로 바뀌며 한 문장을 더 붙인다. |
| 8 | 사진 올리기 | 완성한 책을 펼쳐(한 면에 8쪽이 다 보인다) 노트북 카메라로 찍거나 파일로 올린다. |

화면에는 정답·오답·점수·빨간색이 없다. 노트북 화면 절반(약 640px)에서도 쓸 수 있게 만든다. 버튼은 크게, 안내는 한국어로 한다.

### 교사 화면: 실시간 관전판

- **반 만들기**: 4자리 코드가 생기고, 오늘의 차시를 고른다. 코드는 언제든 바꾸거나 반을 닫을 수 있다.
- **관전판**: 학생(번호) × 쪽(1~6) 격자. 칸마다 우리말 한 줄과 영어 문장이 실시간으로 채워진다. 오래 비어 있는 칸은 눈에 띄게 표시된다. 아이가 묻지 않아도 막힌 곳이 보인다.
- **검색 흐름**: 아이들이 검색한 말이 시간순으로 흐른다. 누가 무엇을 찾다가 멈췄는지 보인다.
- **못 찾은 말 모음**: 사전에 없던 말이 쌓인다. 답을 한 번 쓰면 반 전체에 공지되고 표현사전 후보로 저장된다.
- **이렇게도 말해요 카드**: 칸을 눌러 그 아이에게만 보낸다.
- **문장 벽**: 고른 문장을 큰 화면에 띄우고 앱 소리로 읽어준다. 이름 대신 번호나 별명이 보인다.
- **사진 모음**: 차시별로 아이들이 올린 책 사진을 본다.

### 사진은 무료 요금제에서도 가능하다

Firebase 무료 요금제(Spark)에는 Cloud Storage 무료 사용량이 없다. 대신 앱이 사진을 긴 변 1280px, 300KB 이하 JPEG로 줄여 Firestore 문서에 저장한다. 문서 하나의 한도(1MiB) 안이다. Firestore 무료 사용량은 저장 1GiB, 하루 읽기 5만 번이고, 30명이 7권씩 올려도 약 60MB다([Firebase 요금](https://firebase.google.com/pricing)). 3단계에서 Blaze로 바꾸면 그때 Cloud Storage로 옮겨도 된다.

사진을 줄이는 과정에서 촬영 위치 같은 정보도 지워진다. 올리기 화면에는 “책만 찍고, 얼굴은 나오지 않게”를 띄운다.

### 유글리시(원어민 영상) 연결

- 유글리시가 제공하는 위젯을 앱에 넣는다. 13세 미만이 쓰는 서비스는 제한 모드(Restricted Mode)를 반드시 켜야 한다. “Powered by YouGlish.com” 표시와 YouTube 약관·Google 개인정보처리방침 링크도 필요하다. 상업적 사용은 별도 허락이 필요하다([YouGlish 위젯 안내](https://youglish.com/api/doc/widget)).
- 실제 영상이라 초등학생에게 맞지 않는 장면이 나올 수 있다. 처음에는 교사 화면에서만 쓰고, 괜찮다고 판단되면 교사 설정에서 학생 버튼을 켠다.
- 아이가 버튼을 누르기 전에는 유글리시에 아무 요청도 보내지 않는다(위젯의 Delay Load).

### 데이터 구조

책 내용과 표현사전은 GitHub의 JSON 파일에 둔다. 선생님이 웹에서 바로 고칠 수 있고, 고치면 자동으로 배포된다. 이 문서의 차시별 표(6쪽 설계, 생각 질문, 아이들이 막힐 말)가 첫 내용이 된다.

```json
{
  "lesson": 2,
  "title": "Let Me Introduce My ___",
  "modelBook": [
    {"page": "cover", "image": "books/lesson2/cover.png", "en": "Let Me Introduce My Grandma"},
    {"page": 1, "image": "books/lesson2/p1.png", "en": "This is my grandma. She lives near the sea.", "ko": "우리 할머니야. 바닷가 근처에 사셔."}
  ],
  "pages": [
    {"page": 1, "question": "누구야? 나랑 어떤 사이야?", "frames": {"1": "This is my ___.", "2": "This is my ___. He(She) is ___.", "3": "He(She) is the kind of person who ___."}}
  ]
}
```

```json
{
  "id": "spicy-cry",
  "ko": "매워서 눈물이 났다",
  "tags": ["맵다", "매워", "눈물", "울다"],
  "native": "My mouth was on fire!",
  "easy": "It's so spicy. I cried!",
  "example": "My mouth was on fire, but I couldn't stop eating!",
  "lessons": [3],
  "group": "느낌·맛"
}
```

실시간으로 오가는 것만 Firestore에 둔다.

| 컬렉션 | 담는 것 |
| --- | --- |
| classes | 반 이름, 코드, 교사, 오늘의 차시, 학생용 유글리시 켜짐 여부 |
| classes/{반}/students | 번호 또는 별명 |
| classes/{반}/entries | 차시, 쪽, 우리말 한 줄, 영어 문장, 문장 벽 공유 여부 |
| classes/{반}/searches | 검색어, 찾았는지 여부, 시간 |
| classes/{반}/misses | 못 찾은 말과 선생님의 답 |
| classes/{반}/tips | “이렇게도 말해요” 카드 |
| classes/{반}/photos | 차시, 줄인 책 사진(300KB 이하) |

### 보안과 아동 개인정보

- 학생은 익명 로그인이다. 자기 기록, 자기에게 온 카드, 문장 벽만 볼 수 있고 다른 아이의 기록은 볼 수 없다.
- 교사는 이메일 또는 구글 로그인이고, 자기 반만 전부 본다. 이 구분은 Firestore 보안 규칙으로 강제한다.
- 실명·학교명·얼굴 사진·위치는 받지 않는다. 녹음은 저장하지 않는다. 학기가 끝나면 버튼 하나로 반의 기록을 통째 지운다.
- 가정통신문으로 우리말 답·검색어·문장·책 사진을 선생님이 본다는 것을 미리 알리고, 학교·교육청의 외부 서비스와 생성형 AI 학생 사용 지침을 먼저 확인한다.
- Firebase 웹 설정값은 공개돼도 되는 값이고, 보호는 보안 규칙이 한다. Claude API 키는 절대 앱 코드에 넣지 않는다. GitHub에 올리는 순간 공개된다.

### AI 연결: 원어민처럼 말하기

Claude API는 Cloud Functions for Firebase에서 부른다. Functions는 Blaze 요금제가 필요하고, Blaze에도 매달 무료 사용량이 있다([Firebase 문서](https://firebase.google.com/docs/functions/faq-and-troubleshooting)). 카드 등록이 부담이면 Cloudflare Workers도 대안이다. 어느 쪽이든 예산 알림을 건다.

함수가 지키는 것: 반 코드 확인, 입력 80자 제한, 학생당·반당 호출 상한, 입력 내용은 저장하지 않기. 응답은 아래 형식으로 고정한다.

```json
{
  "native": "My mouth was on fire, but I couldn't stop eating!",
  "easy": "It's so spicy. I cried! But I ate more.",
  "chunks": [
    {"en": "My mouth was on fire", "ko": "입에서 불이 났어(엄청 매울 때)"},
    {"en": "I couldn't stop ___ing", "ko": "~하는 걸 멈출 수 없었어"}
  ],
  "frame": "I couldn't stop ___ing!"
}
```

AI에게 주는 지시의 핵심:

```text
You help Korean elementary students (ages 9-12) say what they want in English for their mini picture books.
Given a Korean sentence, return JSON with:
- native: what an English-speaking child of the same age would naturally say. Idiomatic, under 15 words, so it fits on a small page.
- easy: the same meaning in short, simple sentences a beginner can read aloud.
- chunks: 1-3 reusable phrases, each with a short Korean explanation.
- frame: one fill-in-the-blank pattern the child can reuse.
Never judge the child's language as right or wrong.
If the input contains personal information (full name, address, phone, school), leave it out and add "tip": "개인정보는 책에 쓰지 않아요."
If the input suggests the child is being hurt or is in danger, do not translate. Return {"care": true, "message": "선생님이나 믿을 수 있는 어른에게 꼭 이야기해요."}
Keep everything age-appropriate.
```

care 응답이 나오면 교사 관전판에도 조용히 표시해, 선생님이 수업 뒤 따로 살피게 한다.

### 개발 순서

1. **1단계 · 바로 쓰는 앱(서버 없음)**: 전자책 모델 책, 오늘의 책(생각 질문 → 원어민 표현), 말 찾기, 듣기, 혼자 말해보기, 유글리시(교사 화면 먼저). GitHub Actions로 GitHub Pages에 자동 배포한다.
2. **2단계 · 교실 연결(Firebase 무료)**: 반 코드, 우리말·검색·문장 실시간 관전판, 이렇게도 말해요 카드, 못 찾은 말, 문장 벽, 사진 올리기, 보안 규칙.
3. **3단계 · AI(Blaze)**: 학교 지침을 확인한 뒤 Cloud Functions와 원어민처럼 말하기.
4. **매 단계 끝 점검**: 노트북 크롬·엣지·사파리에서, 창 절반 크기로 한글 입력, 소리, 카메라, 실시간 반영을 확인한다.

### 시작하려면 선생님이 할 일

- [ ] GitHub에 빈 저장소 하나 만들기(예: say-it-your-way)
- [ ] prompts 폴더대로 GPT에서 모델 책 그림을 만들고, 정해진 파일 이름으로 저장하기
- [ ] 2단계 전: Firebase 프로젝트 만들기, 익명·이메일 로그인 켜기, Firestore 만들기, 웹 앱 설정값 복사해두기
- [ ] 2단계 전: 가정통신문(반 코드, 번호, 선생님이 보는 것)
- [ ] 3단계 전: 학교 지침 확인, Blaze 전환과 예산 알림, Claude API 키 발급

구성도(텍스트):
- GitHub 저장소(앱 코드 + src/data/*.json + public/books 그림) → GitHub Actions 자동 배포 → GitHub Pages
- GitHub Pages의 같은 앱이 학생 화면, 교사 관전판, 펼친 모델 책을 함께 제공
- 학생 화면 ↔ Firestore(문장·검색·사진·카드) ↔ 교사 관전판 (실시간, 2단계)
- 학생 화면 → Cloud Functions(API 키 보관·호출 상한) → Claude API (3단계)

1단계는 GitHub만으로 돌아가고, 2단계에서 Firestore가 학생 화면과 교사 관전판을 잇는다. 3단계에서는 API 키를 가진 함수만 Claude API를 부른다.
