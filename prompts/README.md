# 그림 프롬프트 (ChatGPT용)

| 파일 | 무엇 | 그림 수 |
| --- | --- | --- |
| `CHATGPT_START.md` | GPT 대화를 시작할 때 맨 처음 붙여 넣는 지침 | — |
| `00_style-and-characters.md` | 공통 그림체, 등장인물, 캐릭터 시트 | 4장 |
| `01_app-art.md` | 앱 첫 화면 마스코트(선택) | 1장 |
| `lesson2_…` ~ `lesson8_…` | 2~8차시 모델 책(표지, 1~6쪽, 뒷표지) | 7권 × 8장 |

## 만드는 순서

1. `CHATGPT_START.md`의 지침을 GPT에 붙여 넣어요. 앱 분위기 참고 그림(분홍 트럭 그림)이 있으면 같이 올려요.
2. `00_style-and-characters.md`의 캐릭터 시트 4장을 먼저 만들어 저장해요.
3. 책 한 권마다 GPT 새 대화를 열고, 캐릭터 시트와 분위기 참고 그림을 올린 뒤 그 책 파일의 회색 상자를 하나씩 붙여 넣어요.
4. 나온 그림은 상자 위에 적힌 이름으로 저장해요(예: `books/lesson2/p1.png`). `books` 폴더를 통째로 저장소의 `public/books/`에 넣으면 앱의 펼친 책에 그림이 나타나요.
5. 마스코트를 만들었다면 `public/art/mascot.png`로 넣어요.

## 알아둘 것

- **그림에는 글자를 넣지 않아요.** 영어 문장은 앱이 그림 아래쪽에 글자로 얹어요. 그래서 문장을 고쳐도 그림을 다시 만들 필요가 없고, 소리 읽기와 낱말 누르기도 돼요. 그림에 글자가 생기면 `fix text`라고 보내요.
- **쪽 그림은 아래 4분의 1을 비워 둬요.** 영어 문장이 들어갈 자리예요. 표지는 제목 자리로 위 4분의 1을 비워 둬요.
- **그림체**는 앱과 같은 파스텔 그림책 느낌(분홍, 하트 빨강, 크림, 세이지 초록, 꿀색)으로 맞췄어요.
- **선생님 모습은 기본값이에요.** 동그란 안경, 노란 별 핀, 분홍 카디건이에요. 실제 선생님 모습에 맞추고 싶으면 알려 주세요. 프롬프트 56개를 한 번에 바꿔 드려요.
- 5차시는 선생님의 어린 시절 이야기라 어린 선생님(8살)이 주인공이에요. 3차시 5쪽은 고등학생 시절 기억이에요.
